# Dear Nature — Archive

자연을 청자로 삼은 시조와, 이를 극으로 재해석한 대본을 함께 열람하는 정적 웹 아카이브입니다.

현재 수록된 항목은 8주차 아카이브 시트에서 `작업` 표시가 된 여섯 편(인덱스 01·03·06·07·08·15)입니다. 표에서 작품 원문, 현대어 풀이, 작가, 출전, 창작 시기, 자연 청자, 발화 태도와 부여한 역할을 비교할 수 있습니다. 각 행의 **대본 보기**를 누르면 해당 극 대본이 열립니다.

## 구성

- `index.html` — 표와 대본 팝업의 구조
- `style.css` — 화면 및 인쇄 외 읽기 환경의 스타일
- `archive-data.js` — 작품 정보와 대본 데이터
- `app.js` — 표 렌더링과 대본 팝업

별도의 빌드 과정이 없습니다. 로컬에서는 `index.html`을 열어 볼 수 있으며, GitHub Pages를 켜면 저장소 루트에서 그대로 게시할 수 있습니다.

작품 정보와 시조 원문·현대어 풀이는 `김승민_8주차_아카이브`의 `아카이브` 탭을 기준으로 옮겼습니다. 대본은 `C446032_김승민_8주차.pdf`의 장면 면을 웹에서 읽는 순서에 맞춰 전사했습니다. 특히 원형·세로 배열된 대본은 지면의 시각적 배치를 재현하지 않고 대사 순서로 정리했습니다. `전승`·`추정` 표기는 원본 시트에 적힌 불확실성을 유지합니다.
