# Dear Nature — Archive

자연을 청자로 삼은 시조와, 이를 극으로 재해석한 대본을 함께 열람하는 정적 웹 아카이브입니다.

현재 수록된 항목은 8주차 아카이브 시트에서 `작업` 표시가 된 여섯 편(인덱스 01·03·06·07·08·15)입니다. 첫 화면에는 막 번호와 장면 번호·제목만 보입니다. 장면 제목을 선택하면 작품 원문, 세 줄로 나눈 현대어 풀이, 작가, 출전, 창작 시기, 자연 청자, 발화 태도, 부여한 역할과 대본이 펼쳐집니다. 데스크톱에서는 텍스트 왼쪽·무대 이미지 오른쪽, 좁은 화면에서는 세로 순서로 읽습니다.

## 구성

- `index.html` — 장면 목록과 작품 정보, 대본 원고
- `style.css` — 데스크톱·모바일 레이아웃
- `images/scene-01.jpg` ~ `scene-06.jpg` — 각 장면의 무대 이미지. 원본은 수업 폴더의 `Source_hub`에 보관

별도의 빌드 과정이 없습니다. 로컬에서는 `index.html`을 열어 볼 수 있으며, GitHub Pages를 켜면 저장소 루트에서 그대로 게시할 수 있습니다.

작품 정보와 시조 원문·현대어 풀이는 `김승민_8주차_아카이브`의 `아카이브` 탭을 기준으로 옮겼습니다. 대본은 `C446032_김승민_8주차.pdf`의 장면 면을 웹에서 읽는 순서에 맞춰 전사했습니다. 특히 원형·세로 배열된 대본은 지면의 시각적 배치를 재현하지 않고 대사 순서로 정리했습니다. `전승`·`추정` 표기는 원본 시트에 적힌 불확실성을 유지합니다.

내용을 수정할 때는 `index.html`에서 해당 `<details class="scene">`를 고치면 됩니다. 새 장면도 같은 구조로 추가할 수 있습니다. 펼침·접힘은 브라우저의 기본 `details` 동작을 사용해 별도의 자바스크립트가 필요하지 않습니다.
