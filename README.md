# Dear Nature — Archive

자연을 청자로 삼은 시조와, 이를 극으로 재해석한 대본을 함께 열람하는 정적 웹 아카이브입니다.

현재 수록된 항목은 8주차에 작업한 여섯 편(인덱스 01·03·06·07·08·15)과 9주차에 새로 각색한 「풍상이 섞어 친 날에」(인덱스 02)입니다. 첫 화면에는 막 번호와 장면 번호·제목만 보입니다. 장면 제목을 선택하면 작품 원문, 세 줄로 나눈 현대어 풀이, 작가, 출전, 창작 시기, 자연 청자, 발화 태도, 부여한 역할과 대본이 펼쳐집니다. 데스크톱에서는 텍스트 왼쪽·무대 이미지 오른쪽, 좁은 화면에서는 세로 순서로 읽습니다.

## 구성

- `index.html` — 장면 목록과 작품 정보, 대본 원고
- `style.css` — 데스크톱·모바일 레이아웃
- `images/scene-01.jpg` ~ `scene-06.jpg` — 기존 여섯 장면의 무대 이미지. 원본은 수업 폴더의 `Source_hub`에 보관
- `images/hwanggukhwa-stage.jpg` — 9주차 「풍상이 섞어 친 날에」 무대 이미지. 원본은 수업 폴더의 `09. Week_09/이미지`에 보관

별도의 빌드 과정이 없습니다. 로컬에서는 `index.html`을 열어 볼 수 있으며, GitHub Pages를 켜면 저장소 루트에서 그대로 게시할 수 있습니다.

기존 여섯 편의 작품 정보와 시조 원문·현대어 풀이는 `김승민_8주차_아카이브`의 `아카이브` 탭을 기준으로 옮겼고, 9주차에 추가한 작품은 `김승민_9주차_아카이브`의 해당 행을 기준으로 했습니다. 기존 대본은 `C446032_김승민_8주차.pdf`의 장면 면을 웹에서 읽는 순서에 맞춰 전사했고, 9주차 대본은 새 각색 원고를 실었습니다. 특히 원형·세로 배열된 대본은 지면의 시각적 배치를 재현하지 않고 대사 순서로 정리했습니다. `전승`·`추정` 표기는 원본 시트에 적힌 불확실성을 유지합니다.

내용을 수정할 때는 `index.html`에서 해당 `<details class="scene">`를 고치면 됩니다. 새 장면은 확정된 뒤 해당 막의 제목 아래, 원하는 읽기 순서에 같은 구조로 삽입합니다. 화면의 장면 번호·무대 이미지 설명 번호·상단 총수는 HTML에 놓인 `.scene`의 순서와 개수에서 자동으로 정해지므로 뒤쪽 번호를 일일이 수정하지 않습니다. 막 제목은 별도로 유지하며, 번호는 막마다 다시 시작하지 않고 책의 앞쪽부터 이어집니다. `id`, 대본 제목의 `id`, 이미지 파일명은 순서가 아니라 각 작품을 식별하는 고유값으로 취급해 기존 것을 재번호화하지 않습니다. 원문과 대본 등 작품 내용은 계속 `index.html`에 직접 적습니다. 펼침·접힘은 브라우저의 기본 `details` 동작을 사용합니다.
